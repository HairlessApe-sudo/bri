## Assignment 07 — Privacy Shield Foundation (2026-11-14)

Implemented locally as an independent Python package; no production/provider integration is implied:

- `src/bri/privacy/detection.py` provides deterministic signatures for Dutch BSN (elfproef), email, Dutch/international-format phone, checksummed IBAN for an explicit country registry, contextual bank account, Dutch-style postal address, contextual valid DOB, and configured tenant literal signatures/terms. `Detector` is an extension protocol for later local/contextual detection.
- `src/bri/privacy/policy.py` provides deterministic allow/mask/block rules, tenant policy loading, validation and a mandatory platform floor that masks every detected category and cannot be weakened by tenant allow rules. Missing, malformed, wrong-tenant or unavailable policies block.
- `src/bri/privacy/service.py` validates short-lived signed tenant/principal/action/resource/input/purpose/destination context, supports document, historical-case, retrieved-context and user-question text, applies policy and masking/blocking, returns structured results and safe audit metadata, and fails closed on detector, policy, audit, clock or attestation failure.
- `src/bri/privacy/contracts.py` provides HMAC context and short-lived Gateway envelope contracts. The envelope binds sanitized content, tenant/resource scope, input/purpose/destination, allow/mask decision, tenant/platform policy IDs and versions, detection counts and expiry; only AI-provider-bound results receive an envelope. No Gateway is implemented.
- Synthetic tests exercise signatures/checksums, false-positive/false-negative examples, Unicode and overlaps, platform-floor precedence, tenant isolation, scope binding, non-AI destinations, expiry/tampering, safe audit/repr behavior and fail-closed component failures.
